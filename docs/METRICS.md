# Metric catalogue

Generated by `tools/build_powerbi.py` from the same definitions that produce the semantic model — edit there, not here.

Python equivalents (used for `gold_performance` and the quality gate) live in `nb_04_gold` / `nb_common.xirr`.

## Selection

### Selected Currency

Reporting currency picked on the Currency slicer (default USD).

Format: `text`

```dax
Selected Currency =
SELECTEDVALUE ( dim_report_currency[currency_code], "USD" )
```

### As Of Date

Latest quarter end in the current date filter, capped at the latest quarter the administrators delivered.

Format: `yyyy-mm-dd`

```dax
As Of Date =
VAR _picked = MAX ( dim_date[quarter_end_date] )
VAR _latest = CALCULATE ( MAX ( fact_snapshot[period_end] ), REMOVEFILTERS ( dim_date ) )
RETURN
    IF ( ISBLANK ( _picked ), _latest, MIN ( _picked, _latest ) )
```

### Report Title

Dynamic subtitle for page headers.

Format: `text`

```dax
Report Title =
"As of " & FORMAT ( [As Of Date], "mmmm d, yyyy" ) & "  ·  " & SWITCH ( [Selected Currency], "LOCAL", "fund currency", "LE", "legal-entity currency", [Selected Currency] )
```

## Capital

### Commitment

Commitments made on or before the as-of date (converted at commitment-date FX).

Format: `#,0;(#,0)`

```dax
Commitment =
VAR _asof = [As Of Date]
VAR _ccy = [Selected Currency]
RETURN
    CALCULATE ( SWITCH ( _ccy, "USD", SUM ( fact_commitment[commitment_usd] ), "CAD", SUM ( fact_commitment[commitment_cad] ), "LOCAL", IF ( DISTINCTCOUNT ( fact_commitment[local_currency] ) = 1, SUM ( fact_commitment[commitment_local] ) ), "LE", IF ( DISTINCTCOUNT ( fact_commitment[le_currency] ) = 1, SUM ( fact_commitment[commitment_le] ) ) ), fact_commitment[commitment_date] <= _asof )
```

### Paid In

Capital called including fees, from inception to the as-of date.

Format: `#,0;(#,0)`

```dax
Paid In =
VAR _asof = [As Of Date]
VAR _ccy = [Selected Currency]
RETURN
    CALCULATE (
        SWITCH ( _ccy, "USD", SUM ( fact_cashflow[amount_usd] ), "CAD", SUM ( fact_cashflow[amount_cad] ), "LOCAL", IF ( DISTINCTCOUNT ( fact_cashflow[local_currency] ) = 1, SUM ( fact_cashflow[amount_local] ) ), "LE", IF ( DISTINCTCOUNT ( fact_cashflow[le_currency] ) = 1, SUM ( fact_cashflow[amount_le] ) ) ),
        fact_cashflow[flow_category] = "PAID_IN",
        REMOVEFILTERS ( dim_date ),
        fact_cashflow[cashflow_date] <= _asof
    )
```

### Distributions

## Performance

### DPI

Distributed to paid-in.

Format: `0.00"x"`

```dax
DPI =
DIVIDE ( [Distributions], [Paid In] )
```

### RVPI

Residual value (NAV) to paid-in.

Format: `0.00"x"`

```dax
RVPI =
DIVIDE ( [NAV], [Paid In] )
```

### TVPI

Total value to paid-in = DPI + RVPI.

Format: `0.00"x"`

```dax
TVPI =
DIVIDE ( [Distributions] + [NAV], [Paid In] )
```

### Net IRR

LP net IRR: XIRR over calls (−), distributions (+) and NAV (+) at the as-of date, ACT/365.

Format: `0.0%;-0.0%`

```dax
Net IRR =
VAR _asof = [As Of Date]
VAR _ccy = [Selected Currency]
VAR _flows =
    CALCULATETABLE (
        fact_irr_flow,
        fact_irr_flow[level] = "INVESTOR",
        REMOVEFILTERS ( dim_date ),
        fact_irr_flow[as_of_date] = _asof
    )
VAR _ok =
    SWITCH (
        _ccy,
        "LOCAL", COUNTROWS ( DISTINCT ( SELECTCOLUMNS ( _flows, "c", fact_irr_flow[local_currency] ) ) ) = 1,
        "LE", COUNTROWS ( DISTINCT ( SELECTCOLUMNS ( _flows, "c", fact_irr_flow[le_currency] ) ) ) = 1,
        TRUE ()
    )
VAR _t =
    ADDCOLUMNS (
        _flows,
        "@amt",
            SWITCH (
                _ccy,
                "USD", fact_irr_flow[amount_usd],
                "CAD", fact_irr_flow[amount_cad],
                "LOCAL", fact_irr_flow[amount_local],
                "LE", fact_irr_flow[amount_le]
            )
    )
RETURN
    IF ( _ok && NOT ISEMPTY ( _flows ), IFERROR ( XIRR ( _t, [@amt], fact_irr_flow[flow_date] ), BLANK () ) )
```

### Gross MOIC

Deal-level (proceeds + income + fair value) / invested.

Format: `0.00"x"`

```dax
Gross MOIC =
VAR _asof = [As Of Date]
VAR _ccy = [Selected Currency]
VAR _t =
    ADDCOLUMNS (
        CALCULATETABLE (
            fact_irr_flow,
            fact_irr_flow[level] = "INVESTMENT",
            REMOVEFILTERS ( dim_date ),
            fact_irr_flow[as_of_date] = _asof
        ),
        "@amt",
            SWITCH (
                _ccy,
                "USD", fact_irr_flow[amount_usd],
                "CAD", fact_irr_flow[amount_cad],
                "LOCAL", fact_irr_flow[amount_local]
            )
    )
RETURN
    DIVIDE ( SUMX ( FILTER ( _t, [@amt] > 0 ), [@amt] ), - SUMX ( FILTER ( _t, [@amt] < 0 ), [@amt] ) )
```

### Weighted Avg Coupon

Principal-weighted coupon of loans held at the as-of date.

Format: `0.00%`

```dax
Weighted Avg Coupon =
VAR _asof = [As Of Date]
RETURN
    CALCULATE (
        DIVIDE ( SUMX ( fact_accrual, fact_accrual[principal_usd] * fact_accrual[coupon_rate] ), SUM ( fact_accrual[principal_usd] ) ),
```

## NAV Bridge

### Bridge Amount

NAV bridge component in the selected currency for the selected quarter (closing NAV is the waterfall total).

Format: `#,0;(#,0)`

```dax
Bridge Amount =
VAR _ccy = [Selected Currency]
VAR _asof = [As Of Date]
VAR _ok =
    SWITCH (
        _ccy,
        "LOCAL", CALCULATE ( DISTINCTCOUNT ( fact_snapshot[local_currency] ), REMOVEFILTERS ( dim_date ) ) = 1,
        "LE", CALCULATE ( DISTINCTCOUNT ( fact_snapshot[le_currency] ), REMOVEFILTERS ( dim_date ) ) = 1,
        TRUE ()
    )
RETURN
    IF (
        _ok,
        CALCULATE (
            SUM ( gold_nav_bridge[amount] ),
            gold_nav_bridge[currency_code] = _ccy,
            gold_nav_bridge[is_closing] = FALSE (),
            REMOVEFILTERS ( dim_date ),
            gold_nav_bridge[period_end] = _asof
        )
    )
```

Format: `0`

```dax
Checks Passed (latest run) =
VAR _run = CALCULATE ( MAX ( ops_dq_results[run_id] ), ALL ( ops_dq_results ) )
RETURN
    CALCULATE ( COUNTROWS ( ops_dq_results ), ops_dq_results[run_id] = _run, ops_dq_results[passed] = TRUE () )
```
